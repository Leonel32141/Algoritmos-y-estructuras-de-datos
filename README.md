# Algoritmos-y-estructuras-de-datos

En grupos de 3, realizar un proyecto propio según lo visto y explicado en clase.
El proyecto debe ser en Python y deberá integrar los temas vistos en las últimas clases: matrices, tuplas y secuencias, diccionarios y conjuntos (opcional).
Una vez finalizado, subir a un repositorio en Github con los integrantes del grupo.
Deberán especificar el tipo de proyecto y su descripción deberá incluirse en un archivo readme.md

INTEGRANTES: SANTIAGO MONTENEGRO - SEBASTIAN QUINTERO - LEONEL TELLO - IAN VECCHIO

PROYECTO: Este código representa un sistema de gestión y venta de camisetas en línea. Está dividido en varias secciones, donde se incluyen funcionalidades tanto para un administrador como para un usuario final que desea realizar compras.
